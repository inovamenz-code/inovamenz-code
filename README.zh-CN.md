## 精选项目

### [BallDarkEcho](https://github.com/inovamenz-code/ball-dark-echo)
一款 Windows 局域网竞技游戏，玩家的移动和开火通过回声波纹与空间声音暴露位置信息。

我的实现包括组件化玩法，以及连接 Unreal 与 Wwise 的 C++ 音频事件组件。仓库收录了游戏图片、演示视频、Windows 版本和音频设计说明；README 区分了已实现功能与仍待验证的音频工作。

**Unreal Engine · C++ · Blueprint · Wwise · 局域网多人**

### [自适应游戏音乐](https://github.com/inovamenz-code/adaptive-game-music)
已完成并继续迭代的硕士毕设实现：将 Unity 游戏状态发送到 Python 服务，生成 MIDI 或 WAV 音乐后返回游戏播放。

我负责状态采集、受控提示词、服务集成、桌面控制台与播放处理。MIDI-LLM 和 ACE-Step 是我接入的外部模型，并非由我开发的模型。仓库说明了配置依赖和当前限制。

**Unity / C# · Python / FastAPI · MIDI / WAV · PySide6**

### [WM908 生存射击 — 项目介绍](https://inovamenz-code.github.io/projects.html#survival-prototype)
一款 C++ 俯视角生存射击游戏，包含固定与无限地图、敌人生成、拾取物和存档／读档。源码仓库与 Windows 快照目前为私有，公开材料正在准备中。Wwise 集成属于后续计划，尚未实现。
