## Selected projects

### [BallDarkEcho](https://github.com/inovamenz-code/ball-dark-echo)
A Windows LAN arena game where movement and weapon fire reveal players through echo waves and spatial sound.

My implementation includes component-based gameplay and an Unreal-to-Wwise C++ event bridge. The repository contains gameplay images, a demonstration video, a Windows build and audio-design notes. Its README distinguishes implemented features from audio work still awaiting verification.

**Unreal Engine · C++ · Blueprint · Wwise · LAN multiplayer**

### [Adaptive Game Music](https://github.com/inovamenz-code/adaptive-game-music)
My completed MSc dissertation implementation, under continued development: Unity gameplay state is sent to Python services that generate MIDI or WAV music and return it for in-game playback.

My work covers state capture, controlled prompts, service integration, a desktop control console and playback handling. MIDI-LLM and ACE-Step are external models I integrate, not models I authored. Setup dependencies and current limitations are documented in the repository.

**Unity / C# · Python / FastAPI · MIDI / WAV · PySide6**

### [WM908 Survival Shooter — project overview](https://inovamenz-code.github.io/projects.html#survival-prototype)
A C++ top-down survival shooter with fixed and infinite maps, enemy spawning, pickups and save/load. The repository and Windows snapshot are currently private; public materials are being prepared. Wwise integration is planned, not implemented.
